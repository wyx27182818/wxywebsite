## 二、卡点记录（核心）

**卡在哪一步**：任务 2 —— 找出「不含截图」的那种模板。

**当时的心理过程**：
看到任务要求「不含截图」，回头看卡片列表，首先扫的是**卡片标题**——
「小艺资金表版 / 按品类分页版 / 极简金额版 / 不含截图版 / 月汇总版 / 分支明细版」。
标题里其实有「不含截图版」，但我下意识去读**描述**找依据，而描述写的是
「文件小，方便发给别人看」——**这句话里没有出现「截图」两个字**，
"文件小" 和 "不含截图" 之间的因果关系需要自己推一步才能连上。

**用一句话概括卡点**：要选的那张卡，**标题说了「不含截图」，描述却在说另一件事**——
描述原本该是「帮用户确认这就是我要找的」的第二重线索，结果它没接上，反而增加了一次推理。

**这是用词问题还是控件问题**：**用词问题**。控件（卡片、按钮）本身没问题，
「用这套」按钮位置和样式都清楚，选中后的「已选 ✓」也有反馈。

**为什么我自己之前没发现**：因为这张卡的 `name` 是我写的，
我知道「不含截图版」就是这个 id `noshot` 的卡，**我脑子里的索引是 name，不是 desc**。
但第一次用的人会**先读标题确认方向、再读描述确认细节**，
描述没给确认，这一步就悬空了。

---

## 三、最小修复（本次实施）

**改了什么**：`MOCK_TEMPLATES` 里 `noshot` 这张卡的 `desc` 字段。

```
改前：desc:"文件小，方便发给别人看"
改后：desc:"不带截图，文件小，方便发给别人看"
```

**为什么选这一处**：
- 是**一处**、一个字段、几个字，符合「最小修复」要求，不做大改版
- 直击卡点：让描述重新承担「确认这就是你要找的」职责
- 不引入新概念、不动布局、不影响其他五张卡

**复测结果**：改后重看卡片列表，扫描述即可直接确认，
不再需要从「文件小」反推「所以没截图」。✅
