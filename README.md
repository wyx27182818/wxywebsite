# 艺账 · 自己的记账小工具

> 一个**纯前端单文件**的个人支出流水账工具。数据只存在你自己电脑的浏览器里，无账号、无广告、不联网。
>
> 一句话：**菜还是自己家做的放心。**

**v1.0** · 在线使用：https://yizhang-accounting.app.workbuddy.host/

---

## 它解决什么问题

以前：手机付款 → 截图 → 攒着 → 手动录进《小艺资金表》→ 想看总额还得改 SUM 公式。

现在：手机截图传到电脑 → 打开艺账记一笔（挂截图）→ 随时按时间段看总额 → 定期导出和《小艺资金表》一模一样格式的 Excel。

**核心只有一个数：任意时间段内花了多少钱。**

## 能做什么

| 功能 | 说明 |
|---|---|
| 记一笔 | 四个字段：品类 / 时间 / 买什么 / 金额。品类和物资**留空也能存**（自动填默认名），只有金额必填 |
| 挂截图（多张自动拼一张） | 点「＋ 添加截图」逐张加、也可以一次多选；多张自动**左右拼成一张**，一笔账永远只对应一张图 |
| 时间段总额 | 快捷「今天 / 本月 / 全部」+ 自定义起止日期，显示总额与笔数，默认「本月」 |
| 品类无限分支 | 品类名里写 `/` 就分层：`餐饮/水果/进口水果`。列表是棵可折叠的树，**父级小计自动包含所有子分支**；改上级名字，下级跟着走 |
| 列表管理 | 原地改名、归类到任意分支、两段式删除（先点变「确认删除」，再点才真删）、点缩略图看大图 |
| 导出 Excel（.xls） | 一比一复刻《小艺资金表》`9月12日-` 页：品类 / 时间 / 购买物资 / 金额 / 截图 / 总金额，含合并单元格与 `=SUM` 合计 |
| 导出 Excel 含截图（.xlsx） | 截图**真正嵌在 E 列单元格里**，不是浮在表格上的图片，也没有「见图片」文字 |
| 拼长图 | 把当前时间段所有截图按时间竖排成一张长图，每张带「品类 · 物资 · 日期 · 金额」标签条 |
| 固定导出文件夹 | 选一次文件夹，之后导出和备份自动写进去，不用每次再选（浏览器支持时） |
| 自动备份与恢复 | 每次记账 / 改名 / 删除后，账目（含截图）静默写入 `艺账备份.json`；浏览器数据被清掉也能一键找回 |
| 三主题 | 白蓝款（白天）/ 黑白款（夜间）/ 春天版，右上角低调小圆钮循环切换，选择会被记住 |

## 怎么用

1. 打开 https://yizhang-accounting.app.workbuddy.host/ （或本地双击 `index.html`）
2. 填品类 → 选时间 → 写买什么 → 输金额 → 点「＋ 添加截图」挂支付截图 → 点「记一笔」
3. 想按时间段看总额，用上面的快捷按钮或自定义日期
4. 想归档，点「导出 Excel」或「Excel 含截图」；第一次建议先点「导出文件夹」选一个固定文件夹
5. 右上角小圆钮切主题（鼠标放上去会亮起来）

## 本地运行

不需要安装任何东西，两种方式：

**方式一：直接双击** `index.html` —— 浏览器打开就能用（地址栏是 `file://` 开头）。

**方式二：起一个本地服务器**（想看"正规军"的运行方式时用）——在项目根目录执行：

```bash
python -m http.server 8000
```

然后浏览器打开 **http://localhost:8000** 即可。停止服务按 `Ctrl + C`。

说明：
- 这条命令用的是 Python 自带的模块，**不是装了什么服务器软件**——它只是把当前文件夹变成一个"网址"，让你通过 `http://localhost:8000` 访问，本质和双击打开是同一份文件
- `8000` 是端口（同一台电脑上区分不同服务用的编号），被占用时可以换成别的，比如 `python -m http.server 8001`
- 纯前端单文件的好处在这里：**没有 `npm install`、没有构建、没有环境变量**，一条命令就跑起来
- 两种方式数据都在浏览器里且互通（同一个浏览器 = 同一份 IndexedDB）

## 数据在哪：数据流一览

```
手机支付截图 ┐
             ├─→ 手工录入（浏览器页面）─→ IndexedDB（本机浏览器数据库）
手工填的字段 ┘                                  │
                                                ├─→ 你点「导出」──→ .xls / .xlsx / 长图
                                                └─→ 你点「备份」──→ 艺账备份.json（固定文件夹）
```

**没有任何一条线通向互联网。** 断网也能记账、改账、导出。

⚠️ **一件事必须记住**：数据在**浏览器**里，不在这个网页里。所以：
- 换电脑 / 换浏览器 → 数据不会自动跟过去，用「从备份恢复」把 `艺账备份.json` 带过去
- 清理浏览器数据会清掉账目 → 所以才有自动备份，**记得设置固定导出文件夹**
- 网址只是软件本体，谁打开都是空的（各自的数据在各自浏览器里）

## 技术路线（一句话）

**纯前端单文件路线：一个 `index.html` 装下全部界面与逻辑，账目和截图存在浏览器本机的 IndexedDB 里，导出与备份用浏览器自带的文件能力直接写进你指定的文件夹——全程没有服务器，也没有数据库。**

没有后端的原因很简单：只有一个人用、数据不外传，服务器和数据库在这里只会变成成本。代价是换设备看不到数据——这是有意接受的取舍（详见 `TECH_DESIGN.md`）。

## 已知限制（有意为之，不是 bug）

1. **.xlsx 的嵌图只有 WPS 能正常显示**，微软 Excel 打开会显示 `#NAME?`。因为「图片真正钉在单元格里」目前只有 WPS 私有的 DISPIMG 机制能做到——用微软兼容换「图必须在格子里」，是主动选择。
2. **拼长图受浏览器画布高度上限约束**（约 3 万像素），时间段太长会提示缩小范围分批拼。
3. **换设备无法自动同步**，靠备份文件手动搬。
4. **不做 OCR 自动读金额**：本地识别一张要 2–10 秒，达不到「1 秒内」的要求；云端识别快但要把截图传给第三方，违背数据自持。手工填 5 秒搞定。

## 永久不做的事

广告、社区、理财推荐、账号登录、预算报表、报销字段、备注列。
——《小艺资金表》`9月12日-` 页没有的列，艺账也不加。

## 怎么改这个项目

- 没有构建步骤：直接改 `index.html`，浏览器刷新即生效
- 想发布到固定网址：把 `index.html` 复制到 `.workbuddy/site/` 再用发布工具部署（appId 固定，链接不变）
- Excel 格式基准永远以《小艺资金表》`9月12日-` 页为准；**A 列不加「品类」表头**，不设备注/水印列
